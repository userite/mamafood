🧪 Тест на UIK API

💡 Информация:
• За локално тестване използвай: http://localhost:3000
• За production използвай: https://mamafood.onrender.com
• Можеш да вземеш UIK и device_serial от localStorage на основното приложение

⚠️ ВАЖНО - CORS проблеми:
Ако виждаш "Failed to fetch" грешка, вероятно е CORS проблем. Решения:
1. Хоствай файла на локален сървър:
  • Python: python -m http.server 8000
  • Node.js: npx http-server -p 8000
  • След това отвори: http://localhost:8000/test-uik-api.html
2. Или използвай браузър с изключени CORS проверки (само за тестване!)

1️⃣ Проверка на PIN и връщане на UIK

Endpoint: POST /api/uik/verify

💡 Ако няма device_serial в localStorage, ще бъде генериран нов автоматично

2️⃣ Получаване на информация за UIK

Endpoint: GET /api/uik/info/:uik

3️⃣ Регистрация на нов UIK

Endpoint: POST /api/uik/register

4️⃣ Прикачване към съществуващ UIK

Endpoint: POST /api/uik/attach

5️⃣ Тестване от конзолата на браузъра

Ако имаш проблеми с формата, можеш да тестваш директно от конзолата (F12):

Пример за VERIFY:
const uik = 'твоят-uik';
const deviceSerial = localStorage.getItem('mamafood_device_serial');
const pin = 'твоят-pin';

fetch('http://localhost:3000/api/uik/verify', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ uik, device_serial: deviceSerial, pin })
})
.then(res => res.json())
.then(data => console.log('Резултат:', data))
.catch(err => console.error('Грешка:', err));
