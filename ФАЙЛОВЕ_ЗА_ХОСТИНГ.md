# Файлове за качване на хостинг

## 📁 Необходими файлове за frontend

Качи следните файлове в основната директория на хостинга:

### Основни файлове:
1. **index.html** - Главният HTML файл
2. **app_v2.js** - Основната JavaScript логика
3. **styles.css** - Стилове
4. **i18n.js** - Интернационализация (български/английски)
5. **manifest.json** - PWA манифест (за инсталиране като приложение)
6. **service-worker.js** - Service Worker (за офлайн функционалност и кеширане)

### Опционални помощни файлове (не са задължителни):
- **clear-cache.html** - Помощен файл за изчистване на кеша
- **force-reload.html** - Помощен файл за принудително презареждане
- **set-kai-code.html** - Помощен файл за задаване на код "KAI"

## ✅ Как да качиш файловете

1. **Избери хостинг** (например: cPanel, FTP, GitHub Pages, Netlify, Vercel)

2. **Качи файловете** в основната директория (root) на хостинга

3. **Отвори в браузър**: `https://твоят-домейн.com/index.html` или просто `https://твоят-домейн.com/`

---

## ⚠️ Важни бележки

### 1. Backend API
Frontend-ът се свързва с backend API. Увери се, че:
- Backend-ът е достъпен на `https://mamafood.onrender.com` (production)
- Или промени `API_BASE` в `app_v2.js` ако използваш друг backend

### 2. HTTPS е задължителен
- Service Worker работи **само с HTTPS** (или localhost)
- Ако хостингът не поддържа HTTPS, Service Worker няма да работи
- PWA функционалността (инсталиране като приложение) също изисква HTTPS

### 3. CORS настройки
- Backend-ът трябва да разрешава заявки от домейна на хостинга
- Провери CORS настройките в `server.js` на backend-а

### 4. Кеширане
- Файловете имат версии (`?v=10`) за предотвратяване на кеширане
- При обновяване на файлове, увеличавай версията в `index.html`

## 🔧 Тестване след качване

1. Отвори `https://твоят-домейн.com/index.html`
2. Провери конзолата на браузъра (F12) за грешки
3. Тествай добавяне на запис
4. Провери дали Service Worker е регистриран (Application → Service Workers в DevTools)

## 📱 PWA функционалност

Ако всичко е наред, приложението може да се инсталира като PWA:
- На мобилни устройства: "Добави към начален екран"
- На desktop: Икона в адресната лента за инсталиране

---

## 🆘 Ако има проблеми

1. **Service Worker не работи**: Провери дали хостингът поддържа HTTPS
2. **API заявки не работят**: Провери CORS настройките на backend-а
3. **Файлове не се зареждат**: Провери пътищата и правата за достъп
